# ATLANT: Arena Brawl

3D-рогалич-арена с третьего лица на **Three.js**. Полноценные GLB-модели с анимациями,
процедурный звук WebAudio, CC0-саундтрек, частицы, экран-шейд, даш, волны врагов, боссы и
магазин улучшений между волнами.

## Запуск

```bash
npm install
npm start          # или: node server.js
```

Открыть `http://localhost:8080`.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | движение |
| ЛКМ | огонь (зажать — автомат по weapon) |
| Мышь | обзор (pointer lock) |
| Пробел | даш (невосприимчивость + урон врагам) |
| R | перезарядка |
| 1–4 / колесо | переключение оружия |
| P / Esc | пауза |

## Механики

- **Волны**: преступники, дроны, турели, бруталы; каждый 5-й волна — босс Варбот
  (земляной удар, минионы, 2-я фаза).
- **Рогалич**: между волнами магазин из 3 улучшений (удар, скорость стрельбы,
  пробитие, взрывные пули, крит, лечебница и т.д.) и карты unlock оружия
  (Дробовик → Ракеты → Ми́ниган).
- **Звук**: все SFX синтезируются в WebAudio (выстрелы, взрывы, касания, даш,
  UI); саундтрек — CC0-треки (FreePD), если файл недоступен — встроенный
  синтезатор синтвейва.
